# Resort Booking Website

Rresort booking website built with **Node.js** and containerized using **Docker**.
---

## Project Overview

This project demonstrates a full-stack web application with:

- **Frontend:** HTML/CSS, responsive booking form  
- **Backend:** Node.js with Express, handling booking form submissions and returning confirmation  
- **Dockerization:** Containerized for portability and consistent environment  

The backend listens on **PORT 8080**, and the Docker image can be run locally or deployed to a cloud platform.

---

## Features

- Submit booking details (Name, Email, Check-in, Check-out)  
- Backend confirms booking with a personalized response  
- Dockerized application for easy deployment
